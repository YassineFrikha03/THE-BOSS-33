# THE BOSS 33 • Café & Délices

> **Riadh El Andalous - Ariana, Tunisie**  
> Une expérience gastronomique d'exception : cafés de spécialité, crêpes signatures, gaufres, pancakes et saveurs salées.

---

## 🌟 Présentation du Projet

Application web moderne et interactive présentant la **carte officielle de THE BOSS 33** avec ses **117 spécialités** artisanales.

### ✨ Fonctionnalités clés :
- 📱 **100% Responsive** : conçu pour mobile, tablette et écran large.
- 🖼️ **117 Photos HD** : chaque produit dispose d'une photo haute résolution correspondante stockée en local dans les assets.
- 🔍 **Recherche instantanée** : filtrage en temps réel par nom d'article, ingrédient ou catégorie avec compteur dynamique.
- 🏷️ **Filtres intelligents** : onglets par univers gourmands (*Petit Déjeuner & Brunch*, *Cafés & Boissons*, *Délices Sucrés*, *Délices Salés*) et puces de sous-catégories.
- 🔍 **Modale / Lightbox détaillée** : affichage grand format au clic avec prix, descriptif et badges de qualité (*Signature*, *Healthy*, *Populaire*).
- ☕ **Design noir & or luxueux** : bannière d'en-tête thématique avec logo centré et effets visuels soignés.

---

## 🛠️ Stack Technique

- **Framework** : [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling** : Vanilla CSS moderne + TailwindCSS v4
- **Données** : `src/data.js` (117 articles structurés avec prix en Dinars Tunisiens)

---

## 🚀 Installation et Lancement

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/YassineFrikha03/THE-BOSS-33.git
   cd THE-BOSS-33
   ```

2. Installer les dépendances :
   ```bash
   npm install
   ```

3. Lancer en local :
   ```bash
   npm run dev
   ```

4. Compiler pour la production :
   ```bash
   npm run build
   ```
